**Download `Capri-Setup-1.36.0.exe` below and run it.** It installs for your user, with no admin rights or Python needed (Windows 10/11). If Windows says "Windows protected your PC", click **More info**, then **Run anyway** (the installer isn't code-signed).

**New in 1.36:**
- **Capri updates herself.** Once a day she checks for a new version, downloads it in the background, and installs it the next time she starts. You can also right-click her → **Update now**, or say "check for updates". To turn it off: Settings → PC & chat → Updates.
- **Ollama is found however you installed it.** Program Files, a different address (`OLLAMA_HOST`), installed after Capri started... She also uses whatever chat model you've got if `llama3.2` isn't there.

From 1.35 you need to install this version by hand once. After that, updates are automatic.
