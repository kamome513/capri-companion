**Windows:** download `Capri-Setup-1.40.1.exe` below and run it. If you have 1.36 or newer, Capri updates herself. If Windows says "Windows protected your PC", click **More info**, then **Run anyway** (the installer isn't code-signed).

**Linux:** download `Capri-x86_64.AppImage` below, make it executable (right-click → Properties → Permissions → *Allow executing file as program*), and double-click it. If you have 1.37.0 or newer, it updates itself.

**This undoes 1.40.0**, which had a bad bug. It's the same Capri as 1.39.0. If you installed 1.40.0, she updates to this by herself.
