**Windows:** download **`Capri.exe`** below. That one file is the whole app: put it anywhere and double-click it. If you already have Capri, she updates herself. If Windows says "Windows protected your PC", click **More info**, then **Run anyway** (it isn't code-signed). `Capri-Setup-2.6.3.exe` is still here too.

**Mac (new):** download `Capri-macOS.zip` below (Apple-silicon Macs, macOS 11+), unzip it and drag Capri into Applications. The first time, right-click it → **Open**. She lives in your menu bar.

**Linux:** download `Capri-x86_64.AppImage` below, make it executable (right-click → Properties → Permissions → *Allow executing file as program*), and double-click it. If you have 1.37.0 or newer, it updates itself.
